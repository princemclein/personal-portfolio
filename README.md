# Prince Mclein Gonzales | Portfolio

A modern, responsive portfolio website built with React and Vite to showcase my work, skills, and experience as a Graphic Designer and Front-End Web Developer.

## Features

- Responsive design for all devices
- Modern and minimalist UI
- Smooth scrolling navigation
- Project showcase
- Skills section
- Resume download
- Contact form
- Social media links

## Built With

- React
- Vite
- JavaScript
- HTML5
- CSS3
